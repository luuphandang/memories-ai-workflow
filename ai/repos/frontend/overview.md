# Memories Frontend Overview

- Mục tiêu repository: monorepo frontend Next.js cho dự án Memories, khởi tạo theo `initialize_project.md` (task MEMORIES-0001) — gồm 2 ứng dụng độc lập (`public-web`, `admin-web`) dùng chung ~17 package (`packages/*`: ui, design-system, api-client, auth, forms, validation, query, i18n, observability, analytics, editor-core, seo, utilities, config, eslint-config, typescript-config, types). Nhiều page hiện là stub 1 dòng heading (placeholder cho tính năng sau này) — xem `known-issues.md` để biết chi tiết phạm vi thật đã hoàn thiện.
- Framework/runtime/version: Next.js `^14.2.5` (App Router, không dùng Pages Router), React `^18.3.1`, TypeScript `^5.5.4`, Node.js `>=20.0.0`.
- Package manager: npm workspaces (`workspaces: ["apps/*","packages/*"]`, có `package-lock.json`).
- Cách chạy local: `cp .env.example apps/public-web/.env.local` và `apps/admin-web/.env.local` (xem `docs/guides/local-development.md`), `npm install`, sau đó `npm run dev:public` (Next dev, port 3100) hoặc `npm run dev:admin` (port 3200); build production qua `npm run build:public`/`build:admin` (`next build`, `output: 'standalone'`); hoặc dùng `docker/docker-compose.yml` (profile `development`, build qua `docker/Dockerfile` chung với build-arg `APP_NAME`).
- Design system: Tailwind CSS (`^3.4.10`) với 1 preset dùng chung (`packages/design-system/tailwind-preset.js` + `src/tokens.css`, `darkMode: 'class'`); component trong `packages/ui/src/components` viết tay theo phong cách shadcn/ui (CVA + helper `cn()`) nhưng KHÔNG dùng shadcn CLI (không có `components.json`); hiện chỉ có `button`, `card`, `input`, `label`, `toast` — dùng thật `@radix-ui/react-label`, `@radix-ui/react-slot`, `@radix-ui/react-toast`.
- Browser support: chưa có cấu hình/tài liệu cụ thể (không có `browserslist` riêng trong dự án) — mặc định theo baseline của Next.js `^14.2.5`.
