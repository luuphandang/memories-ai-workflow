# Memories Frontend API Client Rules

- Client/library: `packages/api-client/src/http-client.ts` — class `ApiClient` viết tay (get/post/patch/delete) dựa trên `fetch`, tự gắn Bearer header và xử lý refresh-rồi-thử-lại khi gặp 401 (single-flight, không gọi refresh trùng lặp khi nhiều request 401 cùng lúc). `packages/api-client/src/media-client.ts` (`createMediaApi`) là 1 wrapper có type đầy đủ dựng từ type generated cho endpoint `media` — được ghi chú rõ là "reference implementation" chứng minh contract sinh ra thật sự được dùng; các endpoint khác vẫn gọi qua `ApiClient` chung, chưa có wrapper type riêng.
- Auth/token/cookie: access token gắn vào header `Authorization: Bearer <token>` bởi chính `ApiClient`, lấy từ `TokenStore` in-memory (`packages/auth`) — KHÔNG đọc/ghi cookie hay localStorage/sessionStorage cho access token; refresh token là HttpOnly cookie phía server, `ApiClient`/`createAuthTokenProvider()` gọi `fetch(refreshEndpoint, {credentials:'include'})` để lấy access token mới khi cần.
- Cache/retry/cancel: cache/retry ở tầng data-fetching là TanStack Query (`createQueryClient()`: staleTime 30s, retry 1, `refetchOnWindowFocus:false`) — nhưng hiện CHƯA có page nào gọi `useQuery`/`useMutation` thật; retry 401-refresh ở tầng HTTP client là logic riêng của `ApiClient`, không phải TanStack Query retry.
- Error mapping: `packages/api-client/src/errors.ts`'s `ApiClientError.fromBody()` đọc đúng field `errorCode` (cùng `statusCode`/`message`/`correlationId`/`fieldErrors`) từ response lỗi của backend (`{statusCode, errorCode, message, correlationId?, stack?}` — xem `libs/platform/security/global-exception.filter.ts` phía backend); shape này được mirror lại ở `packages/types/src/api-envelope.ts`'s `ApiErrorBody`. `packages/forms/src/api-error-mapping.ts`'s `applyApiErrorToForm()` map `fieldErrors` vào form field cụ thể qua React Hook Form `setError`.
- Type generation: `packages/api-client/src/generated/schema.d.ts` sinh tự động bằng `openapi-typescript` (script `generate` trong `packages/api-client/package.json`, đọc `${OPENAPI_SCHEMA_PATH:-../../../backend/openapi.json}` — tức file `openapi.json` mà backend export qua `npm run export:openapi`); KHÔNG tự sửa tay file generated.
