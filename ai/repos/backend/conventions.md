# Memories Backend Conventions

- Naming: tên file kebab-case kèm hậu tố theo vai trò (`*.use-case.ts`, `*.orm-entity.ts`, `*.repository.ts`, `*.module.ts`, `*.controller.ts`, `*.dto.ts`, `*.spec.ts`); class/interface PascalCase, không tiền tố `I` cho interface; injection token là hằng số SCREAMING_SNAKE_CASE (ví dụ `MEDIA_ASSET_REPOSITORY`, `TOKEN_SERVICE`, `BACKGROUND_JOB_PUBLISHER`, `OUTBOX_REPOSITORY`).
- Dependency injection: constructor injection của NestJS xuyên suốt; port khai báo dưới dạng TS interface + injection token (const), bind sang adapter cụ thể trong `providers` của module sở hữu.
- Error handling: lỗi nghiệp vụ ném dưới dạng `DomainError` (`libs/shared/kernel`, có `DomainErrorKind` + `code` chuỗi ổn định); `GlobalExceptionFilter` (`libs/platform/security`) là nơi DUY NHẤT map exception sang HTTP status + JSON body `{statusCode, errorCode, message, correlationId?, stack?}` (`stack` chỉ có ngoài production).
- Logging: structured JSON qua `nestjs-pino` (`LOG_FORMAT=json` mặc định, `pretty` cho local dev); các field nhạy cảm (authorization header, cookie, password, token, presignedUrl, v.v. — xem `REDACT_PATHS` tại `libs/platform/observability/src/logger.module.ts`) luôn bị redact tự động; mọi log line mang `correlationId` xuyên suốt từ HTTP request tới background job nhờ `CorrelationContext` (`AsyncLocalStorage`).
- Validation/DTO: `class-validator`/`class-transformer` DTO ở boundary controller, áp dụng qua 1 `ValidationPipe` dùng chung (`buildValidationPipe()`: whitelist + forbidNonWhitelisted + transform); mỗi DTO/endpoint có decorator Swagger (`@ApiProperty`/`@ApiResponse`/`@ApiParam`), export ra OpenAPI qua `npm run export:openapi`.
- Async/transaction: `UnitOfWork.withTransaction()` (`TypeOrmUnitOfWork`) bọc các thao tác ghi nhiều repository trong 1 transaction; transaction được lan truyền ngầm cho repository qua `AsyncLocalStorage` (`TypeOrmQueryRunnerContext`), không truyền tường minh qua tham số hàm; thay đổi trạng thái domain nhạy cảm với concurrency dùng CAS nguyên tử (`repository.transitionStatus(expected, next)`) thay vì đọc-rồi-ghi.
- Import/order/format: ESLint `import/order` (nhóm builtin/external/internal/parent/sibling/index, sắp xếp alphabet, có dòng trống giữa nhóm) + `import/no-cycle`; format bằng Prettier (`singleQuote`, `trailingComma: all`, `printWidth: 100`); enforce qua Husky `pre-commit` (`lint-staged`: eslint --fix + prettier --write) và commit message theo Conventional Commits (`commitlint`, scope bắt buộc kebab-case).
