# Memories Backend API Rules

- Protocol/versioning: REST qua HTTP, JSON; prefix toàn cục `/{apiPrefix}/{apiVersion}` (ví dụ `/api/v1`) áp dụng qua `applyGlobalPrefix()` (`apps/api/src/configure-app.ts`), loại trừ `health/liveness`, `health/readiness`, `metrics`; OpenAPI/Swagger export qua `npm run export:openapi` để đảm bảo schema khớp đúng prefix thật.
- Auth/authorization: `JwtAuthGuard` (`libs/platform/security`) xác thực header `Authorization: Bearer <access token>` qua `TokenService`, gắn `request.user` — áp dụng theo từng controller/route bằng `@UseGuards(JwtAuthGuard)` + đọc user hiện tại qua `@CurrentUser()` (không phải guard global); rate limit (throttling) áp dụng GLOBAL cho mọi route có HTTP traffic thật qua `ThrottlerGuard` (đăng ký `APP_GUARD`). Việc phát hành/refresh token (login flow) CHƯA được nối vào endpoint thật nào — `JwtTokenService`/`buildRefreshCookieOptions()` mới là hạ tầng sẵn có cho tính năng auth tương lai; access token không được lưu localStorage/sessionStorage phía frontend theo AC #46.
- Request/response envelope: response thành công trả thẳng DTO (không bọc envelope chung); response lỗi luôn có dạng cố định `{statusCode, errorCode, message, correlationId?, stack?}` (`stack` chỉ xuất hiện ngoài production) do `GlobalExceptionFilter` sinh ra.
- Error code: `errorCode` là chuỗi ổn định — lỗi nghiệp vụ dùng `code` của `DomainError` (ví dụ `media_asset_already_confirmed`, `media_asset_metadata_mismatch`), lỗi HTTP chung (`NotFoundException`, v.v.) dùng `http_exception`, lỗi không xác định dùng `internal_error`.
- Pagination/filter/sort: có sẵn primitive dùng chung `PaginatedResult<T>`/`PaginationParams` (`libs/shared/kernel/src/results/paginated-result.ts`) cho các endpoint danh sách trong tương lai, nhưng CHƯA có endpoint thật nào trong dự án hiện tại sử dụng — module mẫu `media` chỉ có `GET /media/:id` theo id đơn.
- Backward compatibility: chưa có quy tắc versioning/deprecation cụ thể ngoài prefix `apiVersion` (`v1`) đã tách sẵn trong `AppConfig`, cho phép thêm `v2` song song khi cần.
