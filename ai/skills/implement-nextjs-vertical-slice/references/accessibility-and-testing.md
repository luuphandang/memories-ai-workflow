# Accessibility and testing

- Use semantic elements, labels, accessible names and visible focus.
- Support keyboard navigation and focus restoration for dialogs/menus.
- Announce async errors/status where appropriate and preserve adequate contrast.
- Test user-observable behavior, not component internals.
- Cover loading, failure, permission denial, validation and success states.
- Add route/component tests and E2E coverage for critical cross-page flows.
- Use visual regression only for stable, meaningful layouts.
