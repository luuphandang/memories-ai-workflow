# Example Domain Index

Đây là domain mẫu duy nhất. Hãy sao chép thư mục này thành `ai/domains/<feature-name>/` khi bắt đầu một tính năng thật, sau đó thay các marker bằng dữ liệu đã xác minh.

- `overview.md`: phạm vi và thuật ngữ của tính năng.
- `business-rules.md`: quy tắc nghiệp vụ.
- `api-contract.md`: hợp đồng API hoặc interface.
- `data-flow.md`: luồng dữ liệu tổng quát.
- `workflow.md`: trạng thái và hành vi người dùng/hệ thống.
- `validation-rules.md`: quy tắc kiểm tra dữ liệu.
- `decisions.md`: quyết định và lý do.
