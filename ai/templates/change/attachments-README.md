# Attachments

Đặt hoặc liên kết bằng chứng phục vụ change cycle tại đây.

- Không lưu secret, token, dữ liệu production hoặc dữ liệu cá nhân thật.
- Ghi nguồn và mô tả của từng file/link trong `user-request.md`.
- File lớn nên lưu ở hệ thống quản lý tài liệu của dự án và chỉ ghi đường dẫn tham chiếu.
